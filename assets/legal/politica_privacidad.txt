Política de privacidad de SaneApp

1. Recopilación de datos
SaneApp recopila datos personales para mejorar la experiencia del usuario.

2. Uso de datos
Los datos se utilizan para personalizar servicios y cumplir requisitos legales.

3. Seguridad
SaneApp protege la información mediante medidas técnicas y administrativas.

4. Derechos del usuario
El usuario puede solicitar acceso, rectificación o eliminación de sus datos.

5. Contacto
Para consultas sobre privacidad, escribe a privacidad@saneapp.com
